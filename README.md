# Quiz Java

Programa en Java de preguntas tipo test con resultados finales y barra de progreso. Lo desarrollé yo sola como proyecto de práctica.

## Tecnologías
- Java
- Apache NetBeans

## Funcionalidades
- Preguntas de tipo test
- Barra de progreso durante el test
- Resultados al terminar

## Cómo ejecutarlo
1. Descarga o clona el repositorio.
2. Ábrelo con Apache NetBeans.
3. Ejecuta el proyecto con **Run**.
